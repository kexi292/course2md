# Feature：按逻辑文件夹导出最新笔记

日期：2026-09-20
状态：已实现，待原生交互验收

## 目标

用户会逐节将课程视频生成笔记，并把属于同一门课程的笔记归入同一个逻辑文件夹。本功能将该文件夹中的每篇笔记以最新可读版本导出为一个 Markdown 文件夹，供后续 AI 按笔记名称理解原课程内容。

本功能不负责判断课节顺序。笔记显示名称是交给 AI 判断课序的主要依据。

## 用户结果

用户在“我的笔记”中选择一个真实逻辑文件夹，执行“导出文件夹”，选择保存位置后得到：

```text
所选位置/
└── 逻辑文件夹名称/
    ├── 第一节课程名称.md
    ├── 第二节课程名称.md
    ├── 第三节课程名称.md
    └── assets/
        ├── image-<content-hash>.jpg
        └── image-<content-hash>.png
```

每个 Markdown 文件保留该笔记已有的标题、来源、时长、可选摘要、时间戳正文和图片引用。多个文件共享 `assets`，图片使用内容摘要命名以避免冲突并允许自然去重。

导出目录中不生成课程级摘要或课节索引。文件名及每篇笔记自身的元数据已经足够表达本次约定的课程结构。

## 范围

### 包含

- 仅导出当前选中的真实逻辑文件夹，不包含“全部笔记”或“未分类”。
- 导出文件夹内全部已归类笔记，不受当前搜索词、列表/卡片模式或分组折叠状态影响。
- 每篇笔记导出课程库当前指针指向的最新可读版本；当前版本不可读时，沿用课程库已经采用的最近完好版本回退结果。
- 输出 Markdown 正文和正文引用的图片。
- 导出期间显示真实的已处理篇数和总篇数。
- 单篇失败不删除其他成功结果；最终明确报告成功数和失败笔记。
- 导出在后台进行，用户可以继续浏览其他页面。

### 不包含

- 不增加课节序号、自然数字排序、拖拽排序或顺序字段。
- 不增加新的“课程”实体；逻辑文件夹仍是现有分类。
- 不批量创建笔记，不处理播放列表或合集导入。
- 不合并成单个超大 Markdown 文件。
- 不生成课程级 AI 摘要、知识图谱、学习目标或复习题。
- 不提供 HTML、JSON 等文件夹级格式选择。
- 不修改单篇笔记现有导出菜单。
- 不持久化导出历史。

## 当前实现偏差

- `desktop/src/organize.rs` 只保存“笔记路径 -> 文件夹 ID”的逻辑归类，足以确定导出范围，但没有文件夹级导出操作。
- `desktop/src/notes.rs` 已通过 `current.json` 读取当前版本，并在当前版本损坏时回退到最近完好版本，可直接作为“最新可读版本”的来源。
- `desktop/src/reader_ui.rs` 的导出入口只接受当前打开的一篇 `Course`。
- `src/portable.rs` 的 Markdown 导出是单篇 ZIP，其中固定包含 `course.md` 和图片；不能直接组成一个共享资源目录下的多篇 Markdown。
- 笔记库当前按修改时间展示。该顺序只影响界面，不应写入导出语义。

## 导出规则

### 范围快照

点击导出并选定目标位置后，固定以下快照：

- 课程库 ID 和规范化根目录；
- 文件夹 ID 和当时的显示名称；
- 当时归入该文件夹的笔记路径；
- 每篇笔记当时解析出的版本目录和显示名称。

后续重命名文件夹、移动笔记或发布新版本不改变正在执行的这一次导出。下一次导出再读取最新状态。

### 文件名

- 使用笔记在课程库中的显示名称，而不是内部哈希目录名。
- 使用现有共享文件名净化规则处理 Windows/macOS/Linux 非法字符；空名称回退为“未命名笔记”。
- Windows 保留设备名（如 `CON`、`PRN`、`AUX`、`NUL`、`COM1`）在净化后加前缀 `_`，不能等到写入时才把整篇记为失败。
- 同一导出中净化后重名时，保留第一篇为 `名称.md`，后续使用 `名称 (2).md`、`名称 (3).md`。
- `_导出未完成.md` 和 `assets` 是内部保留名称；同名笔记按普通重名规则改名，不能覆盖失败说明或资源目录。
- 重名分配只为避免覆盖，不表示课节顺序。
- 文件名比较同时考虑目标文件系统的大小写规则，不能因 `Lesson`/`lesson` 覆盖内容。

### 目标目录

- 原生目录选择器让用户选择父目录，应用在其中创建以逻辑文件夹名称命名的子目录。
- 不覆盖已有目录。若同名目录已存在，自动选择 `文件夹名称 (2)`、`文件夹名称 (3)` 等可用名称。
- 先在所选父目录内写入同文件系统的临时目录，完成后再重命名为最终目录，避免留下看似完整的半成品。
- 如果至少一篇成功，则发布成功内容；如果全部失败，则不发布最终目录并清理临时目录。

### 内容

- 复用单篇便携导出的已验证 `Document`、Markdown 渲染和图片安全路径规则，不从界面文本重新拼接正文。
- 每篇 Markdown 的图片引用改写为共享的相对路径 `assets/image-<content-hash>.<ext>`。
- 不写入课程库私有绝对路径。
- 不修改课程库、版本目录、现有单篇导出或手工文件。
- 同一图片摘要对应同一资源文件；已写入的相同内容不重复复制。

### 部分失败

若部分笔记失败，成功笔记仍发布，并额外写入 `_导出未完成.md`：

```markdown
# 导出未完成

已导出 7/8 篇笔记。

- 《某节课程》：笔记正文无法读取
```

失败说明只包含笔记显示名称和可操作的安全错误，不泄露内部路径、凭据或服务响应。全部成功时不生成该文件。

## UI 交互设计

### 入口

入口位于“我的笔记”页工具栏，仅在选中真实逻辑文件夹时显示：

```text
[文件夹：机器学习 ▼] [新建文件夹] [管理文件夹 ▼] [↓ 导出文件夹]
```

- 使用现有 `outline_pill` 和共享 `download` 图标。
- “导出文件夹”是当前文件夹内容的次级操作，不放入“管理文件夹”菜单；重命名/删除管理分类本身，导出处理分类内的内容，两者职责不同。
- “全部笔记”和“未分类”不显示该入口，避免把筛选范围误认为课程边界。
- 空文件夹显示禁用入口；辅助提示为“文件夹中没有可导出的笔记”。
- 搜索结果为空但文件夹实际包含笔记时仍允许导出，并在按钮提示中明确“导出文件夹中的全部笔记”。

分组视图的组标题暂不增加第二个快捷入口。用户先选择文件夹再导出，保持第一阶段只有一个可解释的操作位置。

### 开始

1. 用户点击“导出文件夹”。
2. 打开原生目录选择器，标题为“选择导出位置”。
3. 用户取消选择时直接返回，页面和筛选保持不变，不显示失败。
4. 用户选定目录后立即开始，无需再展示格式或课序确认弹窗。

格式固定为 Markdown 文件夹，文件名来自现有笔记名称，因此没有尚待用户决定的必要选项。

### 进行中

工具栏原位置保持稳定：

```text
[⟳ 正在导出 3/12]
```

- 使用实际完成篇数作为确定进度，不估算百分比或剩余时间。
- 导出按钮在本次操作期间禁用，避免重复启动；标签和图标占用稳定宽度，不推动相邻控件。
- 文件系统工作在后台执行，渲染函数不读写文件。
- 用户可以切换页面或打开笔记；导出不会抢回导航。
- 第一阶段不提供中途取消。该操作只读取现有版本并写入新目录，不发起网络请求，也不覆盖既有文件。

### 完成

用户仍停留在同一文件夹时，在工具栏下方显示与该文件夹绑定的低强调结果行：

```text
✓ 已导出 12 篇笔记                         [打开文件夹] [关闭]
```

- “打开文件夹”调用现有系统打开能力。
- 结果行不使用模态框，不创建完成页，不改变列表滚动位置。
- 用户已经离开该文件夹时只保存本次会话反馈；返回对应文件夹后显示，不主动切页。
- 再次成功导出替换该文件夹上一次会话反馈。

### 部分完成

```text
△ 已导出 11/12 篇；《第三节》未完成       [打开文件夹] [重新导出] [关闭]
```

- 多个失败时显示数量，展开详情后按笔记逐项列出原因。
- “重新导出”重新打开目录选择器并重新读取当时最新的文件夹状态；不向已有导出目录补写，也不覆盖成功结果。
- `_导出未完成.md` 让用户在离开应用后仍能识别资料包不完整。

### 全部失败

```text
× 未能导出“机器学习”：笔记正文暂时无法读取  [重新导出] [关闭]
```

- 不创建最终目录，不声称已保存。
- 保留原课程库和所有笔记。
- 错误与重试留在发起操作的文件夹上下文。

### 失效与并发

- 目录选择器打开期间若文件夹被重命名或归类变化，以用户确认目录后的快照为准。
- 课程库在开始前离线时不启动导出，并在入口附近显示“课程库暂时无法访问”。
- 导出开始后某个版本消失或变化，只将对应笔记记为失败，不中断其他笔记。
- 同一应用实例同时只运行一个文件夹导出；其他文件夹的入口保持禁用并提示当前正在导出。
- 晚到的完成回调必须校验导出代次和 `(library_id, folder_id)`，不能覆盖后来一次导出的反馈。

## 布局与视觉约束

- 工具栏沿用现有搜索、文件夹筛选和次级按钮的共同控制轴，不新增页面或卡片。
- 普通宽度下，导出入口与“管理文件夹”同组；空间不足时按现有工具栏规则整体换行，不缩小文字或裁切标签。
- 100%、125%、150%、200% 字号下按真实文本测量控件；“正在导出 999/999”不得与相邻控件重叠。
- 图标、文字、加载态和焦点态使用共享主题、控件和状态层；不定义页面私有颜色或动画。
- 结果行自然换行，操作保持在同一资源边界内；窄窗时操作移至下一行，不使用固定高度。
- 保留普通键盘焦点顺序、原生目录选择器行为和既有系统动效偏好，不扩展为专项无障碍工程。

## 状态模型

| 状态 | 入口/反馈 | 用户操作 |
| --- | --- | --- |
| 未选择真实文件夹 | 不显示导出入口 | 选择文件夹 |
| 空文件夹 | 禁用“导出文件夹” | 导入或生成笔记 |
| 可导出 | 显示“导出文件夹” | 选择目标位置 |
| 选择器取消 | 恢复原状态 | 无需恢复 |
| 导出中 | 显示真实篇数进度，入口禁用 | 可继续浏览 |
| 全部成功 | 成功结果行 | 打开文件夹、关闭 |
| 部分成功 | 成功数/总数及失败详情 | 打开文件夹、重新导出、关闭 |
| 全部失败 | 明确原因，不发布目录 | 重新导出、关闭 |
| 课程库离线 | 入口不可执行并显示原因 | 重新连接后再导出 |

## 实现边界

### `src/portable.rs`

- 增加把一个已验证版本写为“Markdown 文件 + 外部共享资源目录”的最小导出能力。
- 复用现有图片类型识别、内容摘要、Markdown 渲染和安全资源路径。
- 在文件导出边界补齐 Windows 保留设备名处理，不改变课程存储目录的身份规则。
- 保留现有单篇 ZIP/HTML/JSON API 和行为。

### `desktop/src/course_library.rs`

- 在选中真实文件夹时渲染导出入口和结果行。
- 导出范围取自文件夹归类，不取当前搜索后的可见列表。

### `desktop/src/folder_export.rs`

- 承担范围快照、原生目录选择、后台批量写入、目标目录发布、进度和部分失败汇总。
- 状态使用导出代次隔离晚到回调。
- 该模块是桌面逻辑文件夹语义的拥有者；核心导出模块不认识桌面文件夹 ID。

### `desktop/src/main.rs`

- 保存单个活动导出及按 `(library_id, folder_id)` 关联的会话反馈。
- 不新增持久化工作区字段或迁移。

## 验证计划

### 核心导出测试

- 两篇笔记导出为两个 Markdown，共享资源目录中的图片引用可解析。
- 相同图片只写一次，不同图片不会重名。
- 非法字符、空名称、大小写冲突和同名笔记均不会覆盖。
- Windows 保留设备名及内部保留名称可正常导出且不会覆盖说明文件。
- 输出不包含课程库绝对路径。
- 目标同名目录已存在时创建新目录并保留原内容。
- 单篇损坏时发布其他成功笔记并生成 `_导出未完成.md`。
- 全部失败时不留下最终目录或临时目录。

### 桌面状态测试

- 只有真实文件夹显示入口；空文件夹禁用。
- 搜索不会缩小导出范围。
- 导出快照固定，运行期间移动/重命名笔记不改变本次集合。
- 离开页面后完成不会改变当前导航，返回原文件夹可看到反馈。
- 晚到回调不会覆盖新导出状态。
- 目录选择取消不产生错误或残留忙碌状态。

### 原生验收

- 在 Windows 原生应用中验证普通/窄/宽窗口，以及浅色/深色和全部内置配色。
- 验证 100%、125%、150%、200% 字号下的工具栏换行、进度标签和结果操作。
- 验证空文件夹、正常导出、部分失败、全部失败、课程库离线和重复导出。
- 验证导出的 Markdown 和图片在课程库之外可独立读取，并实际将整个文件夹交给支持多文件上下文的 AI 检查理解效果。

## 验收标准

- 用户最多经过“选择文件夹 -> 导出文件夹 -> 选择位置”即可得到资料包。
- 导出的集合等于操作开始时该逻辑文件夹内所有可识别笔记，不受搜索影响。
- 每篇使用当时最新可读版本，文件名来自显示名称，不承诺或伪造课节顺序。
- 所有输出可在原课程库移走或离线后独立读取。
- 不覆盖用户已有文件，不修改原笔记；失败时明确哪些笔记未导出。
- 导出过程不阻塞界面、不抢夺导航，也不新增完成页。
