# Windows 桌面端首次配置反馈 TODO（2026-09-11）

关联反馈：`docs/feedback/2026-09-10-windows-desktop-setup.md`

## 用户目标

Windows 用户只需要：

1. 看到当前模型实际读取的目录；
2. 在桌面端直接修改这个目录；
3. 保存后立即知道模型是否可用；
4. AI 服务未配置时，仍能使用本地视频 + 本地 ASR 完成转换；
5. 点击 Windows 标题栏关闭按钮后，应用真正退出。

## 明确不做

- 不要求用户理解 `config.toml`、`desktop-preferences`、旧配置迁移或备份。
- 不在普通设置页展示配置来源、优先级和内部恢复文件。
- 不因为这次反馈重做整个偏好系统。
- 不修改发布标签，不替换已发布资产。
