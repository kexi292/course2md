# Feature：笔记面板快捷创建课程文件夹

日期：2026-09-18  
状态：第一阶段已实现，Windows release 测试包交由用户原生实测。

## 用户问题

在笔记面板整理课程时，没有方便、直接的新建课程文件夹入口。用户应能先创建分类文件夹，再导入或整理笔记，不必返回新建笔记流程。

本文将“笔记面板”理解为笔记库列表/卡片页。阅读器内的快捷归类作为后续扩展，不纳入第一阶段。

## 现状与原因

- `desktop/src/course_library.rs` 的 `library_toolbar` 提供筛选、显示方式和已有文件夹管理，但没有新建入口。
- `library_controls_visible` 在没有课程、没有筛选、没有搜索且没有错误的空库中隐藏整个工具栏，直接在现有工具栏追加按钮仍不能解决首次创建。
- `desktop/src/library_ui.rs` 已有 `begin_folder`、`save_folder` 和创建/重命名弹窗。创建成功会更新索引并进入新文件夹，无须另建存储模型。
- `folder_menu` 只列出未分类和已有文件夹，没有“新建并移入”。
- `desktop/src/import_ui.rs` 已有新建文件夹入口，可复用其共享控件、图标及创建流程。
- 当前文件夹是课程库内的逻辑分类，不等同于磁盘目录；不应因本功能移动已发布笔记文件或创建新的物理存储规则。

## 第一阶段方案

1. 在笔记面板的文件夹筛选附近增加“新建文件夹”次级操作，使用共享 `create_new_folder` 图标和现有按钮样式。
2. 空库显示独立的新建入口，与导入笔记操作相邻。不要为了露出按钮强制展示没有意义的搜索、分组等整套控件。
3. 复用现有创建弹窗和保存逻辑；名称输入自动获得焦点，取消返回原位置，保持已有键盘行为。
4. 创建成功后选中新文件夹、刷新筛选项，并显示该文件夹的空状态。当前搜索词若会遮蔽新文件夹内容，成功后清除；取消或失败则保留原搜索与筛选。
5. 新文件夹空状态提供“导入到此文件夹”。仅更新本次未提交输入的课程库和文件夹，不改全局默认位置，也不改已提交任务快照。

### 课程库归属

- 单课程库：直接在该库创建。
- 已选某课程库/文件夹：创建同库的平级文件夹，当前版本不引入嵌套层级。
- 聚合“全部笔记”且有多个库：在创建弹窗中明确显示并允许选择所属课程库，不能依赖不可见的上一次 `library_root` 值。
- 弹窗打开时固定本次创建目标，后台刷新不能把创建操作切换到其他库。

### 失败与保存

- 空白名称、同名处理等沿用现有组织层规则；实现前检查规则并补齐对应提示，不另设一套校验。
- 库离线、索引损坏或写入失败时保留名称和弹窗，在操作处显示原因，不展示创建成功。
- 创建完成但后续草稿归属保存失败时，沿用现有分步错误提示，重试不得重复创建。
- 不在渲染函数内读写文件；检查现有创建入口的磁盘操作是否需要移到既有后台任务机制。

## 后续扩展

在笔记的移动菜单中增加“新建文件夹并移入”。创建目标应锁定为该笔记所属课程库，创建或归类失败保留原笔记位置。该流程需要携带笔记上下文，不能直接调用会跳转页面的 `begin_folder(None)` 就视为完成。

暂不加入嵌套文件夹、拖拽、批量管理、跨库迁移或磁盘目录创建。

## 实施范围

| 文件 | 改动方向 |
| --- | --- |
| `desktop/src/course_library.rs` | 常驻创建入口、空库入口、新文件夹空状态 |
| `desktop/src/library_ui.rs` | 复用创建流程，明确课程库上下文，处理成功后的筛选 |
| `desktop/src/import_ui.rs` | 导入到指定文件夹的未提交草稿衔接 |
| 现有组织层和 workspace 测试 | 名称规则、保存失败、草稿与任务快照隔离 |

遵循 `.agents/skills/course2md-design/SKILL.md`，复用共享颜色、图标、控件和弹窗，不新造页面样式。

## 验收清单

- [ ] 空库、已有笔记、文件夹筛选、搜索无结果时，都能找到新建入口。
- [ ] 列表与卡片模式行为一致；单库和多库目标明确。
- [ ] 创建后立即进入新文件夹，重启后仍存在。
- [ ] 从新文件夹导入后归属正确，已有草稿和已提交任务不被误改。
- [ ] 取消、空名称、重名、离线、索引损坏及保存失败都有明确行为。
- [ ] 在运行中的 Windows 原生应用验证普通/窄窗口、浅色/深色及放大文字，无控件重叠或入口被裁切。

## 实施与验证记录

- 已增加笔记工具栏及空库新建入口，复用共享按钮、图标和创建弹窗。
- 弹窗固定目标库；聚合视图可明确选择所属库，名称与失败原因保留在弹窗中。

- 导入只更新未提交输入的归属；已有内容与选项保留，已提交输入建立新输入，默认库及任务快照不变。
